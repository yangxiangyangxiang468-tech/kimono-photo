# きものフォト

写真を撮ると、着物を着た写真になる。スマホのブラウザで動き、ホーム画面に入れるとアプリのように使える。

公開URL: https://yangxiangyangxiang468-tech.github.io/kimono-photo/

- `index.html` 1ファイルで動く（ビルド不要）。`manifest.webmanifest`・`sw.js`・`icons/` はホーム画面に追加してアプリとして使うためのもの
- 写真は端末の中だけで処理し、どこにも送らない

## 使い方

1. 「写真を撮る・選ぶ」で、正面を向いて立った人の写真（上半身か全身）を撮る
2. 柄（麻の葉・青海波・桜・矢絣・市松）と色（朱・紺・桃・萌黄・藤・墨）を選ぶ。写真を長押しすると元の写真と比べられる
3. 「保存」で端末に保存、「送る」で共有
4. 「着る人」で女の人・男の人を選べる

## 着付けゲーム

はじめの画面の「着付けゲーム」から遊ぶ、写真とは別のモード。用意したキャラ（女の子・男の子。`drawChar` で絵として描く）に、着物を正しい順番で着せる。柄と色は毎回かわる。タイムとまちがいの数で ★1〜3 の評価が出て、いちばん速い記録が残る。

キャラは始める前はふだんの洋服、ゲーム中は肌着から着せていく。絵の右下の「↻ 後ろを見る」で後ろ姿（お太鼓・貝の口・袴の腰板・羽織の背紋）も見られる。着付け体験でお太鼓・貝の口を結ぶときは、自動で後ろを向く。

モードは 2 つ。

- **順番クイズ**：品物を正しい順番でタップして着せる（タップするとすぐ着る）。タイムとまちがいで評価する（下の表）
- **着付け体験**：本物の着付けの手順（女の人：長襦袢 → 衿合わせ → 着物 → 裾の長さ決め → 腰紐 → おはしょり → 衿合わせ → 伊達締め → 帯を巻く → 帯を締める → お太鼓 → 帯揚げ → 帯締め、男の人：長襦袢 → 衿合わせ → 着物 → 裾 → 衿合わせ → 腰紐 → 角帯を巻く → 締める → 貝の口 → 袴 → 袴の紐 → 羽織 → 羽織紐）を、1 つずつ指で体験する。裾は上下に動かしてくるぶしで指をはなす、帯の締め具合はメーターが緑のところで指をはなす。100 点から、合わなかった分だけ「仕上がり」の点が減る。レベルは合わせる幅（簡単 = 広い、難しい = せまい）

順番クイズの品物:

| レベル | 女の人 | 男の人 | まちがえたとき |
|---|---|---|---|
| 簡単 | 長襦袢 → 着物 → 帯 | 長襦袢 → 着物 → 角帯 | 次の品物を教えてくれる |
| 普通 | 長襦袢 → 着物 → 帯 → 帯揚げ → 帯締め | 長襦袢 → 着物 → 角帯 → 羽織 → 羽織紐 | 理由が出て +3秒 |
| 難しい | 肌襦袢 → 長襦袢 → 着物 → 伊達締め → 帯 → 帯揚げ → 帯締め | 肌襦袢 → 長襦袢 → 着物 → 角帯 → 袴 → 羽織 → 羽織紐 | 説明なしで +5秒 |

## iPhone で使う

1. このリポジトリを GitHub に置き、Settings → Pages で「Deploy from a branch」・`main`・`/ (root)` を選んで公開する（https で配信されることが必要）
2. iPhone の Safari で公開された URL（https://yangxiangyangxiang468-tech.github.io/kimono-photo/ ）を開く
3. 共有ボタン →「ホーム画面に追加」。以後はアイコンからアプリのように全画面で開ける
4. 「保存」を押すと共有シートが開くので、「画像を保存」を選ぶと写真アプリに入る

## しくみ（index.html 内）

- AI は Google MediaPipe（`@mediapipe/tasks-vision`、端末の中で動く。初めてのときに約30MBを読み込み、`sw.js` が保存して2回目からはすぐ使える）
  - Pose Landmarker（lite）で肩・ひじ・手首・腰・ひざ・足首の位置を見つける
  - Image Segmenter（selfie multiclass）で、写真の 1 点ごとに「背景・髪・肌・顔・服・小物」を見分ける
- `==KIMONO START==` 〜 `==KIMONO END==`: 写真と体の位置から着物を描く処理（画面には触らないので node でも動かせる）
  - 着ている服と腕・脚（首より下、手と足元をのぞく）をまるごと着物の柄で覆い、その上に振袖の袖・身ごろ・衿（右前）・帯・帯揚げ・帯締めを描く
  - 写真の光（明るさ・光の色）と元の服のしわを着物に写し、ふちを少し暗くして丸みを出し、細かい布目と帯の影を足して、布らしく見せる
  - 顔・髪・手は着物の手前に残す
- 柄は `patternTile` で描く（画像ファイルは使わない）
- 横向きや歩いている写真は苦手（脚の形に沿って柄がつく）
